# Vikingos Bar and Food · Menú digital

Menú web estático (HTML, CSS y JS sin dependencias) publicado con GitHub Pages:
https://felipep17.github.io/vikingos-menu/

- Pedido por WhatsApp (sin pasarela de pagos), con salsas por cada 6 alitas.
- Barrio con sugerencias de los nombres oficiales de Cali; la comuna se agrega sola al mensaje.
- Para editar productos, precios, salsas o el número, modifica el bloque `<script>` de `index.html` (`MENU`, `SAUCES`, `WHATSAPP`).
